# yarden-social-slides

Public image host + pipeline code for Yarden's daily social posts (TikTok / Facebook / Instagram via Buffer).

- `slides/YYYY-MM-DD/` — rendered 1080x1920 slides, one folder per day (fetched by Buffer via raw.githubusercontent.com)
- `pipeline/` — slide template, renderer, Buffer publisher, runbook, and the photo library

Control panel: https://claude.ai/artifact/PC2hpZ5R9ECSYjWd55FCwx
